# Im Fediverse folgen (ActivityPub)

Jede Organisation hat einen Fediverse-Akteur, dem du von Mastodon, Pleroma oder jeder anderen ActivityPub-kompatiblen Plattform aus folgen kannst.

Das Handle wird auf der Seite jeder Organisation angezeigt:

```
@{akteur}@{domain}
```

Das Handle im Fediverse-Client suchen und auf Folgen klicken. Neue Veranstaltungen erscheinen dann im Home-Feed, sobald sie veröffentlicht werden.

Über den gemeinsamen Relay-Akteur kannst du Veranstaltungen aller Organisationen auf einmal empfangen — sein Handle wird auf der Organisationsliste angezeigt.
