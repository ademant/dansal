# Veranstaltungen durchsuchen

Über die Filterleiste auf der Startseite kannst du die Ergebnisse eingrenzen:

- **Zeitraum** — Start- und Enddatum wählen
- **Organisation** — nach einer bestimmten Gruppe filtern
- **Tanzstil** — nur Veranstaltungen mit einem bestimmten Tanz anzeigen
- **Typ** — Ball, Workshop, Festival oder Session

Klicke auf einen Veranstaltungstitel, um die Detailseite zu öffnen — dort findest du die vollständige Beschreibung, eine Kartenansicht und Buchungsmöglichkeiten.

Das Kalender-Symbol bei jeder Veranstaltung ermöglicht einen direkten iCal-Download nur für diese eine Veranstaltung.
