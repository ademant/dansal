# Veranstaltungen erstellen und bearbeiten

Das Veranstaltungsformular ist in Abschnitte unterteilt. Das **?** neben einem Abschnittstitel führt direkt zur passenden Stelle auf dieser Seite.

## Grundinformationen

- **Titel** — öffentlicher Name der Veranstaltung (Pflichtfeld)
- **Datum / Uhrzeit** — Beginn und Ende; bei mehrtägigen Veranstaltungen ein Enddatum abweichend vom Startdatum setzen
- **Tags** — Typ auswählen (Ball, Workshop, Festival, …); Workshop-Tags blenden Schwierigkeitsstufen ein
- **Veröffentlicht** — angehakt = öffentlich sichtbar; abgehakt = Entwurf
- **Abgesagt** — markiert die Veranstaltung als abgesagt; sie bleibt sichtbar, aber mit dem Badge „Abgesagt"
- **Beschreibung** — Markdown-Formatierung wird unterstützt (Überschriften, Fett, Links, Listen)
- **Website / Buchungs-URL** — externe Links, die auf der Veranstaltungsseite erscheinen

## Musiker

Namen im Suchfeld eingeben und auf ein Ergebnis klicken, um einen Musiker hinzuzufügen. Mehrere Musiker können verknüpft werden. Musikerliste unter **Admin → Musiker** verwalten.

## Tanzstile

Einen oder mehrere Tanzstile auswählen. Die Liste wird unter **Admin → Verwaltung → Tänze** gepflegt.

## Veranstaltungsort

Bestehenden Ort aus der Dropdown-Liste wählen oder direkt einen neuen Ort anlegen. Für neue Orte genügen Name und Stadt — die Geocodierung kann später unter **Admin → Veranstaltungsorte** vorgenommen werden.

## Organisation

Veranstaltung einer bestehenden Organisation zuordnen oder direkt eine neue anlegen.

## Speichern

Auf **Speichern** klicken. Die Checkbox **Veröffentlicht** steuert die Sichtbarkeit. Entwürfe sind nur für angemeldete Nutzer sichtbar.

Mit **Als Vorlage speichern** am Ende des Formulars können die aktuellen Werte als wiederverwendbare Vorlage gespeichert werden.
