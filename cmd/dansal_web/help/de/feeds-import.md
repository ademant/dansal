# Veranstaltungen aus Feeds importieren

Unter **Admin → Feed-URLs** werden automatische Quellen verwaltet.

## Unterstützte Formate

- **iCal / ICS** — Standard-Kalenderformat
- **JSON** — Gancio- oder dansal-kompatible JSON-Feeds
- **RSS** — manche Veranstaltungsaggregatoren nutzen RSS

## Feed hinzufügen

1. **+ Feed-URL hinzufügen** anklicken
2. Feed-URL einfügen
3. Format auswählen (wird wenn möglich automatisch erkannt)
4. Optional: Organisation zuweisen, Tags hinzufügen
5. **Speichern** klicken

Der Feed wird beim nächsten automatischen Poll-Zyklus abgerufen. Mit **Ausführen** einen sofortigen Abruf starten.

## Vorlagen

Eine Veranstaltungsvorlage auf einen Feed anwenden, um Felder zu befüllen, die die Quelle nicht liefert (Organisation, Tanzstile, Tags). Vorlagenmodus wählen:

- **Feed dominiert** — Vorlage füllt nur leere Felder
- **Vorlage dominiert** — Vorlagenwerte überschreiben Feed-Werte

## Importierte Veranstaltungen prüfen

Importierte Veranstaltungen erscheinen in der Veranstaltungsliste. Den Filter **Unveröffentlicht** nutzen, um sie vor der Freigabe zu prüfen.
