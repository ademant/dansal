# Veranstaltungsorte verwalten

Unter **Admin → Veranstaltungsorte** werden alle Orte angezeigt.

## Geocodierung

Das Suchfeld oben auf der Bearbeitungsseite nutzen, um eine Adresse über OpenStreetMap Nominatim zu finden. Auf ein Ergebnis klicken, um Koordinaten und Adressfelder automatisch zu befüllen. Der Kartenmarker kann auch verschoben oder Koordinaten manuell eingetragen werden.

## Felder

- **Name** — vollständiger Ortsname (Pflichtfeld)
- **Kurzname** — Abkürzung für kompakte Listen
- **Adresse, PLZ, Stadt, Land** — für Karte und iCal-Export
- **Ländercode** — zweistelliger ISO-Code (z. B. `DE`)
- **Website** — Link zur eigenen Seite des Ortes
- **Hinweise** — freier Text, der auf dem öffentlichen Profil des Ortes angezeigt wird (Markdown wird unterstützt)
- **Organisationen** — Ort einer oder mehreren Organisationen zuordnen

## Duplikate zusammenführen

Zwei oder mehr Orte über die Checkboxen in der Listenansicht auswählen, dann auf **Zusammenführen** klicken. Der erste ausgewählte Ort bleibt erhalten; alle anderen werden in sämtlichen Veranstaltungen durch ihn ersetzt.
