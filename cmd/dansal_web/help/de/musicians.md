# Musiker verwalten

Unter **Admin → Musiker** können Musikereinträge erstellt und bearbeitet werden.

## Musiker anlegen

Bandname (Pflichtfeld) sowie optional Kurzname, Website, Beschreibung und Social-Media-Handles eintragen.

## MusicBrainz-Link

Falls der Musiker in MusicBrainz gelistet ist, die MBID eintragen. Sie wird als Link auf der öffentlichen Profilseite angezeigt und ermöglicht zukünftige Anreicherungen aus der MusicBrainz-Datenbank.

## Verknüpfung mit Veranstaltungen

Musiker werden im Veranstaltungsformular verknüpft. Im Abschnitt **Musiker** einen Namen im Suchfeld eingeben und auf ein Ergebnis klicken. Derselbe Musiker kann mit mehreren Veranstaltungen verknüpft werden.
