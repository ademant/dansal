# Veröffentlichungsablauf

## Entwürfe

Eine neu erstellte Veranstaltung ist standardmäßig ein **Entwurf** (Checkbox „Veröffentlicht" nicht angehakt). Entwürfe sind nur für angemeldete Nutzer in der Admin-Veranstaltungsliste sichtbar — im öffentlichen Kalender erscheinen sie nicht.

## Veröffentlichen

Checkbox **Veröffentlicht** ankreuzen und speichern. Die Veranstaltung ist sofort öffentlich sichtbar.

## Absagen

Checkbox **Abgesagt** ankreuzen, um eine Veranstaltung als abgesagt zu markieren. Sie bleibt in der öffentlichen Liste mit dem Badge „Abgesagt" — so werden Besucher informiert, die sie möglicherweise bereits im Kalender haben.

## Vorschläge

Über das Vorschlagsformular eingereichte Veranstaltungen erscheinen unter **Admin → Veranstaltungen** mit aktivem Filter „Vorschläge". Prüfen, ggf. bearbeiten, dann veröffentlichen.

## Feed-Importe

Über externe Feeds importierte Veranstaltungen werden automatisch veröffentlicht, wenn die Feed-Quelle entsprechend konfiguriert ist. Einstellung unter **Admin → Feed-URLs → Bearbeiten**. Den Filter **Unveröffentlicht** in der Veranstaltungsliste nutzen, um importierte Entwürfe vor der Freigabe zu prüfen.
