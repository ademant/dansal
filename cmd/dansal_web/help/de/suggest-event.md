# Veranstaltung einreichen

Wenn du von einer Veranstaltung weißt, die noch nicht eingetragen ist, kannst du sie zur Prüfung einreichen.

1. **Veranstaltung vorschlagen** in der Navigationsleiste anklicken
2. Veranstaltungsdetails ausfüllen — Titel, Datum, Ort und Link zur Veranstaltungsseite
3. Absenden — du erhältst eine Bestätigungs-E-Mail
4. Ein Moderator prüft den Vorschlag und veröffentlicht ihn bei Eignung

Deine E-Mail-Adresse wird nur zur Bestätigung der Einreichung und zur Benachrichtigung über das Ergebnis genutzt. Sie ist nicht öffentlich sichtbar.
