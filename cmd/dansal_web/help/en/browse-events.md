# Browsing events

Use the filter bar on the main page to narrow down events:

- **Date range** — pick a start and end date to limit results to a specific period
- **Organisation** — filter by a specific organising group
- **Dance style** — show only events with a particular dance
- **Event type** — ball, workshop, festival, or session

Click an event title to open the detail page, which shows the full description, location map, and booking options.

The calendar icon on each event opens a direct iCal download for that event alone.
