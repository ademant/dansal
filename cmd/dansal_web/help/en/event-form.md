# Creating and editing events

The event form is divided into sections. Click the **?** next to any section heading to jump to the relevant part of this page.

## Basic information

- **Title** — the public name of the event (required)
- **Date / Time** — start and end date and time; for multi-day events set an end date different from the start date
- **Tags** — select the event type (ball, workshop, festival, …); workshop tags reveal difficulty checkboxes
- **Published** — tick to make the event publicly visible; untick to keep it as a draft
- **Cancelled** — tick if the event has been called off; it stays listed with a "Cancelled" badge
- **Description** — Markdown formatting is supported (headings, bold, links, lists)
- **Website / Booking URL** — external links shown on the event detail page

## Musicians

Type a name in the search box and click a result to add a musician. Multiple musicians can be linked to the same event. Manage the musician list under **Admin → Musicians**.

## Dance styles

Select one or more dance styles. The list is managed under **Admin → Management → Dances**.

## Location

Choose an existing venue from the dropdown or create a new one inline. For a new location, entering a name and town is enough to save — geocoding can be completed later under **Admin → Locations**.

## Organisation

Link the event to an existing organisation or create a new one inline.

## Saving

Click **Save** to store the event. Use the **Published** checkbox to control public visibility. Draft events are visible only to logged-in users.

To save the current form values as a reusable template, use the **Save as template** button at the bottom of the form.
