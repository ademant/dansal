# Managing locations

Go to **Admin → Locations** to see all venues.

## Geocoding

Use the search box at the top of the location edit page to find an address via OpenStreetMap Nominatim. Click a result to fill in coordinates and address fields automatically. You can also drag the map marker or type coordinates manually.

## Fields

- **Name** — full venue name (required)
- **Short name** — abbreviated version used in compact lists
- **Address, postcode, town, country** — used for maps and iCal export
- **Country code** — two-letter ISO code (e.g. `DE`)
- **Website** — link to the venue's own site
- **Notes** — free-text notes shown on the venue's public profile (supports Markdown)
- **Organisations** — assign the location to one or more organisations

## Merging duplicates

Select two or more locations using the checkboxes in the list view, then click **Merge**. The first selected location is kept; all others are replaced by it across every event.
