# Managing musicians

Go to **Admin → Musicians** to create and edit musician entries.

## Creating a musician

Fill in the band name (required) and optionally a short name (used in compact displays), website, description, and social media handles.

## MusicBrainz link

If the musician appears in MusicBrainz, enter their MBID. It is shown as a link on their public profile page and enables potential future enrichment from the MusicBrainz database.

## Linking musicians to events

Musicians are linked from within the event form. In the **Musicians** section, type a name in the search box and click a result to add them. The same musician can be linked to multiple events.
