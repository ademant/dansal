# Publishing workflow

## Drafts

A newly created event is a **draft** by default (the *Published* checkbox is unchecked). Drafts are visible only to logged-in users in the admin event list — they do not appear on the public calendar.

## Publishing

Tick **Published** in the event form and save. The event becomes publicly visible immediately.

## Cancelling

Tick **Cancelled** to mark an event as called off. The event stays in the public list with a *Cancelled* badge, so attendees who already have it in their calendar are informed.

## Suggestions

Events submitted via the suggestion form appear in **Admin → Events** with the *Suggestions* filter active. Review, edit if needed, then publish.

## Feed imports

Events imported from external feeds are published automatically if the feed source is set to auto-publish. Review the setting under **Admin → Fetch URLs → Edit**. Use the *Unpublished* filter in the event list to review imported drafts before they go live.
