# Suggesting an event

If you know of an upcoming event that is not yet listed, you can submit it for review.

1. Click **Suggest event** in the navigation bar
2. Fill in the event details — title, date, location, and a link to the event page
3. Submit — you will receive a confirmation email
4. A moderator reviews the suggestion and publishes it if appropriate

Your email address is used only to confirm the submission and notify you of the outcome. It is not shown publicly.
