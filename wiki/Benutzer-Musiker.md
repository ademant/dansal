# Musikerprofile verwalten

Musiker lassen sich als eigenes Objekt verwalten, so dass auch Termine einer Gruppe dargestellt werden können.

Es gibt zwei Wege, Musiker zuzufügen. Beim Erstellen einer Veranstaltung kann eine Gruppe direkt angelegt werden, allerdings ohne weitere Informationen. Diese können später nachgepflegt werden.

## 🎻 Musiker hinzufügen

1. Gehe zu **Musiker → Neuen Musiker hinzufügen**
2. Details ausfüllen:
   - Name, Beschreibung
   - MusicBrainz-ID (verlinkt zum MusicBrainz-Profil des Musikers)
   - Social-Media-Links (Mastodon, Instagram usw.)
   - Website, SoundCloud-, Bandcamp-Links

## 🎵 Funktionen des Musikerprofils

- **Kommende Veranstaltungen**: Zeigt alle Veranstaltungen, bei denen dieser Musiker auftritt
- **MusicBrainz-Link**: Verlinkung zum Profil des Musikers auf musicbrainz.org

## 🔗 Medien-Links (Videos, Audio, Bilder)

Zusätzlich zu den Social-Media-Feldern lässt sich eine beliebig lange Liste externer Links pflegen, z. B. mehrere YouTube-Videos, Livemitschnitte oder Fotoseiten.

1. Im Musikerprofil den Abschnitt **Medien-Links** öffnen
2. **+ Link hinzufügen** wählen, die Art (Video, Audio, Bild, Sonstiges) einstellen, optional einen Titel eingeben und den Link (muss mit `https://` beginnen) einfügen
3. Mit **↑ / ↓** die Reihenfolge ändern, mit **×** einen Link entfernen
4. Speichern – die Links erscheinen in dieser Reihenfolge im Abschnitt „Medien“ auf der Musikerseite

Die Links werden bewusst nur als einfache Links angezeigt und **nicht eingebettet**: Beim Aufruf der Musikerseite wird nichts von YouTube & Co. geladen, ein Besucher verlässt dansal erst, wenn er auf einen Link klickt. Darüber steht ein Hinweis, dass externe Seiten den Besucher verfolgen können. Pro Profil sind bis zu 20 Links möglich.

## 🖼️ Galerie (eigene Bilder hochladen)

Neben dem einen Profilfoto kann ein Musikerprofil eine kleine Bildergalerie haben. Die Bilder werden auf dansal hochgeladen und von dort ausgeliefert – Besucher laden also nichts von fremden Seiten.

1. Im Musikerprofil den Abschnitt **Galerie** öffnen
2. Unter **Bilder hinzufügen** eine oder mehrere Bilddateien auswählen (jeweils höchstens 1 MB); sind sie KI-generiert, das Häkchen darunter setzen
3. Speichern – die Bilder erscheinen danach in der Liste des Abschnitts
4. Dort lässt sich zu jedem Bild eine **Bildunterschrift** eintragen, die Reihenfolge mit **↑ / ↓** ändern, das Häkchen **KI-generiertes Bild** setzen oder ein Bild mit **Entfernen** zum Löschen markieren; alles wird beim nächsten Speichern übernommen

Auf der Musikerseite erscheinen die Bilder als Vorschaubilder im Abschnitt „Galerie“; ein Klick öffnet das Bild in voller Größe. Wie viele Bilder pro Profil möglich sind, steht unter der Liste (Standard: 8). Lade nur Bilder hoch, an denen du die Rechte hast, und nur mit Einverständnis der erkennbaren Personen. Ortsangaben aus Handyfotos (GPS) werden beim Hochladen automatisch entfernt.

## MusicBrainz

Die Datenbank MusicBrainz enthält primär Daten zu CD's von Musikern. Die Musiker selbst werden mit verschiedenen Informationen gespeichert. Bei Gruppen können auch die einzelnen Mitglieder gepflegt werden, womit dann auch eine Suche möglich ist, in welchen Gruppen ein bestimmter Musiker mitwirkte.
