# Daten pflegen

Für Nutzer gibt es verschiedene Möglichkeiten, Veranstaltungen zu pflegen.

Neben der großen Liste, die über den Menü-Link oben erreicht werden kann, können die Veranstaltungen auch direkt bei den Veranstaltungsorten oder Organisationen verwaltet werden. Bei den Orten und Organisationen gibt es zwei Ansichten: Eine Sicht, die auch den Besuchern dargestellt wird und eine Verwaltungssicht, in der die Veranstaltungen auch über Mehrfachauswahl verarbeitet werden können.

## Löschen von Veranstaltungen

Das Löschen von Veranstaltungen ist zeitlich begrenzt möglich: für normale Nutzer **einen Monat nach Erstellung**, spätestens aber **einen Monat vor Beginn** (mindestens die ersten **7 Tage** nach Erstellung). Administratoren können jederzeit löschen. Ist eine Veranstaltung schon eine Zeit sichtbar, ist es besser, sie abzusagen – die Absage wird auf der Seite transparent dargestellt.

## Übersicht mit Mehrfachselektion

In dieser Tabelle werden die Veranstaltungen dargestellt.

Pro Zeile:
- **Datum**: Vorsortiert nach Datum der Veranstaltung
- **Titel**: Mit Link zur normalen Ansicht der Veranstaltung
- **Ort**: zugewiesener Ort, wo die Veranstaltung stattfindet
- **Organisation**: zugewiesener Verein
- **Status**: Veröffentlicht oder noch nicht sichtbar
- **Kurzlinks**: Direkt Editieren, Buchungen (falls aktiviert), Direkt absagen, Direkt löschen

Links neben der Tabelle sind verschiedene Aktionen für eine Mehrfachauswahl:
- **Zusammenführen**: Speziell über Import können Duplikate entstehen, die hier zu einer Veranstaltung wieder zusammengeführt werden.
- **Vorlage anwenden**: Eine Vorlage auf die ausgewählten Veranstaltungen anwenden.
- **Ort Zuweisen**: Die ausgewählten Veranstaltungen können einem Ort zugewiesen werden.
- **Organisation zuweisen**: Die ausgewählten Veranstaltungen können einer Organisation zugewiesen werden.
- **Terminserie**: Zuweisen zu einer Terminserie
- **Weitere…**: Verschiedene Eigenschaften (Tags, Tanzstile, Essen, Getränke, Barrierefreiheit, Eintritt) können den ausgewählten Veranstaltungen zugewiesen werden.
- **Absagen**: Die ausgewählten Veranstaltungen werden abgesagt.
- **Quelle erneut prüfen**: Die Herkunftsquelle der ausgewählten Veranstaltungen neu abrufen.
- **Löschen**: Die ausgewählten Veranstaltungen endgültig löschen (nur Administratoren).


## Terminempfehlungen

Besucher können Veranstaltungen empfehlen. Diese sind zunächst nicht veröffentlicht. Über den Filter **„Nicht verifiziert"** (👁️, mit Zähler `*`, sofern offene Einträge vorhanden sind) lassen sie sich anzeigen und einzeln veröffentlichen. Empfehlungen können auch abgelehnt werden; der Ablehnungsgrund wird dem Empfehlenden per E-Mail mitgeteilt.

## Duplikate

Der automatische Import funktioniert nicht immer einwandfrei, da Veranstaltungen aus einem iCal-Feed nicht immer zuverlässig einer bereits gespeicherten Veranstaltung zugeordnet werden können. Entsprechende Veranstaltungen werden markiert und lassen sich über den Button **„Mögliche Duplikate"** anzeigen. In der Liste tragen sie ein Badge **„Mögliches Duplikat"** mit einem Link **„Klären"**, über den das Duplikat paarweise aufgelöst werden kann.
