# Daten pflegen

Für Nutzer gibt es verschiedene Möglichkeiten, Veranstaltungen zu pflegen.

Neben der großen Liste, die über das Menu link oben erreicht werden kann, können die Veranstaltungen auch direkt bei den Veranstaltungsorten oder Organisationen verwaltet werden. Bei den Orten und Organisationen gibt es zwei Ansichten: Eine Sicht, die auch den Besuchern dargestellt wird und eine Verwaltungssicht, in der die Veranstaltungen auch über Mehrfachauswahl verarbeitet werden können.

## Löschen von Veranstaltungen

Das Löschen von Veranstaltungen ist nur kurz nach Erstellen der Veranstaltungen möglich bzw. wenn die Veranstaltung noch weit in der Zukunft liegt. Ist eine Veranstaltung schon eine Zeit sichtbar, ist es besser, die Veranstaltung abzusagen. Dies wird dann auf der Seite transparent dargestellt.

## Übersicht mit Mehrfachselektion

In dieser Tabelle werden die Veranstaltungen dargestellt.

Pro Zeile:
- **Datum**: Vorsortiert nach Datum der Veranstaltung
- **Titel**: Mit Link zur normalen Ansicht der Veranstaltung
- **Ort**: zugewiesener Ort, wo die Veranstaltung stattfindet
- **Organisation**: zugewiesener Verein
- **Status**: Veröffentlicht oder noch nicht sichtbar
- **Kurzlinks**: Direkt Editieren, Direkt absagen, Direkt löschen

Links neben der Tabelle sind verschiedene Aktionen für eine Mehrfachauswahl:
- **Zusammenführen**: Speziell über Import können Duplikate entstehen, die hier zu einer Veranstaltung wieder zusammengeführt werden.
- **Ort Zuweisen**: Die ausgewählten Veranstaltungen können einem Ort zugewiesen werden.
- **Organisation zuweisen**: Die ausgewählten Veranstaltungen können einer Organisation zugewiesen werden.
- **Terminserie**: Zuweisen zu einer Terminserie
- **Weitere...**: Verschiedene Eigenschaften (Typ wie Ball/Workshop/Festival, Essen / Getränke oder Eintritt) können den ausgewählten Veranstaltungen zugewiesen werden.
- **Absagen/Löschen**: Die ausgewählten Veranstaltungen können abgesagt oder gelöscht werden.


## Terminempfehlungen
Besucher können Veranstaltungen empfehlen. Diese sind zunächst nicht veröffentlicht. Diese lassen sich über den Filter "Unveröffentlicht" anzeigen lassen. Diese müssen einzeln veröffentlicht werden.

## Duplikate

Der automatische Import funktioniert nicht immer einwandfrei, da Veranstaltungen aus einem iCal-Feed nicht immer einwandfrei einer bereits gespeicherten zugeordnet werden können. Dann werden entpsrechende Veranstaltungen markiert und können über den Butten "Mögliche Duplikate" angezeigt werden.
