# Veranstaltungsorte verwalten

Veranstaltungsorte werden separat von Veranstaltungen verwaltet. Damit müssen diese Informationen nicht immer einer Veranstaltungen zugefügt werden. Speziell durch Geokoordinaten lassen sich die Veranstaltungen auf einer Karte anzeigen. Den Orten werden Eigenschaften zugeordnet, wie z.B. kostenloser Parkplatz, die dann direkt bei den Veranstaltungen mit angezeigt werden.

Ein Veranstaltungsort kann von mehreren Organisationen verwendet werden.

## 🏢 Veranstaltungsort anlegen

1. Gehe zu **Orte → Neuen Ort hinzufügen**
2. Details des Veranstaltungsorts ausfüllen:
   - Name, Kurzname, Adresse
   - Adresse am Besten direkt in das Suchfeld eingeben: Aus gefundenen Orte das passende aussuchen, dann werden Adresse und Koordinaten automatisch übernommen.
   - Geokoordinaten (für die Kartenanzeige)
   - Website, Kontaktinformationen
   - Barrierefreiheit
   - Parkplatzinformationen
   - Details zum Tanzboden (Belag)

Über ein Suchfeld kann aus der Adresse die Koordinaten über Openstreetmap gesucht werden. Wird das Gebäude gefunden, wird die Adresse und die Koordinaten übernommen. Dies ist zwingend erforderlich, um den Veranstaltungsort auf einer Karte anzeigen zu können.

## 🔗 Veranstaltungsorte einer Organisation zuordnen

1. Veranstaltungsort bearbeiten
2. Organisation aus der Dropdown-Liste auswählen
3. Änderungen speichern

Ein Veranstaltungsort kann mehreren Organisationen zugeordnet sein.

## Veranstaltung in einem bestimmten Ort anlegen

Auf der Administrationsseite eines Ortes lässt sich eine Veranstaltung anlegen, wobei der Ort direkt vorausgewählt ist. Ein Schritt bei der Erstellung entfällt dann.
