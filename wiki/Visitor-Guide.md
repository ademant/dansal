## Introduction

Dansal is a platform that makes it easy to find all kinds of dance events - from folk dances and tangos to salsa festivals and workshops. As a visitor, you can:

- Discover events near you
- Access detailed information about events, venues, and musicians
- Connect with other visitors
- Filter events by date, location, and type

## Discovering Events

### Map View

On the homepage, you'll see an interactive map showing upcoming events. The map displays:

- **Markers** for each event location
- **Color coding** by event type
- **Clusters** when there are many events in one region

You can:
- Zoom in and out of the map
- Click on markers to see basic event information
- Click "More Details" to go to the full event page

### Calendar View

Below the map is a weekly calendar view:

- **By default**, the current week is displayed
- Each day shows all events for that day
- You can use the arrow buttons to go forward or backward one week
- Click on a date to go to the day view

### Event Details

On an event's detail page, you'll find:

**Basic Information:**
- Event title
- Date and time (including duration)
- Event location with address
- Organizing organization

**Description:**
- Detailed description of the event
- Type of event (ball, workshop, festival, etc.)
- Difficulty level (if workshop)

**Practical Information:**
- Pricing information and ticket options
- Booking link (if available)
- Organizer contact information

**Schedule (if available):**
- Detailed timetable for multi-day events
- Information about different rooms or slots
- Assignment of musicians to specific times

**Musicians:**
- List of performing musicians or bands
- Links to more information about the artists

**Map and Directions:**
- Interactive map showing the event location
- Route planning options
- Information about parking

## Event Types

Dansal supports different types of dance events:

**Balls:**
- Social dances and formal dance events
- Often with live music
- May have thematic orientations

**Workshops:**
- Dance lessons and learning events
- Different difficulty levels:
  - Beginner
  - Advanced
  - Professional
- Often with well-known dance teachers

**Festivals:**
- Multi-day dance events
- Combination of workshops, balls, and social activities
- Often with international participation

**Combinations:**
- Some events combine multiple formats
- Example: Festival with workshops during the day and ball in the evening

## Location Information

Each venue has a detailed page with:

- **Address information:** Street, postal code, city, country
- **Geocoordinates:** For accurate map display
- **Contact details:** Phone, email, website
- **Accessibility:** Information about barrier-free access
- **Parking:** Availability and costs
- **Dance floor:** Information about size and characteristics
- **Amenities:** Cloakroom, restrooms, catering, etc.

You can search for locations or view all events at a specific location.

## Musicians and Bands

Dansal integrates information about musicians:

- **Musician profiles:** Short description and style
- **Link to MusicBrainz:** For detailed discographies
- **Social media:** Links to Mastodon, Instagram, Facebook, etc.
- **Event list:** All future performances by the musician

Click on a musician's name to learn more about the artist and find other events where this musician is performing.

## Organizations and Clubs

Clubs and organizations have their own profiles with:

- **Contact information:** Website, email, social media
- **Event overview:** All future events
- **Regular venues:** Locations frequently used
- **Description:** Information about the club and its activities

## Community Features

### Ridesharing and Accommodation

Each event page has a community board for:

- **Ridesharing:** Offers and requests
- **Accommodation:** Room offers or search for overnight stays
- **Ticket exchange:** Buying and selling tickets

**Note:** Posts are only visible after the author has confirmed their email address. This ensures that all posts come from real people.

## Multilingual Support

Dansal supports 8 languages, including:

- German
- English
- French
- Spanish
- And more...

You can change the language in the settings or the platform will automatically use your browser language.

## Mobile Usage

The Dansal web interface is fully mobile-optimized:

- **Responsive design:** Adapts to all screen sizes
- **Touch optimization:** Large buttons and easy navigation
- **Swipe gestures:** Easy browsing through weeks and months
- **Quick access:** Important information is always visible

## Frequently Asked Questions

**Q: Do I need to register to see events?**
A: No, all event information is publicly accessible without registration.

**Q: How current is the event information?**
A: The information is updated regularly. Organizers can maintain their data directly.

**Q: Can I filter events?**
A: Yes, you can filter by date, location, event type, and other criteria.

**Q: How can I contact the organizer?**
A: Each event page contains the organizer's contact information.

**Q: Is there an app for Dansal?**
A: Currently there is no native app, but the website is fully mobile-optimized.

**Q: Can I export events to my calendar?**
A: Yes, many events offer iCal export for your personal calendars.

## Tips for Visitors

1. **Plan early:** Popular events are often booked up quickly
2. **Check contact information:** Some events require pre-registration
3. **Use the community board:** Find rideshares or accommodations
4. **Try different languages:** Some information may only be available in certain languages
5. **Check back regularly:** New events are constantly being added

## Support

If you have questions or need support:

- Check the FAQ section
- Contact the organizer directly via the event page
- For technical problems, contact the platform administrator

Enjoy dancing with Dansal!
